## 2. What officially changes for 2026-27 (announced 2026-07-20/21)

Source of record: [All you need to know about changes to FPL for 2026/27 (premierleague.com)](https://www.premierleague.com/en/news/4679873/all-you-need-to-know-about-changes-to-fpl-for-202627), [What's new in 2026/27 Fantasy: Changes to Bonus Points System (premierleague.com)](https://www.premierleague.com/en/news/4679946/whats-new-in-202627-fantasy-changes-to-bonus-points-system), cross-checked with [FFS](https://www.fantasyfootballscout.co.uk/2026/07/20/fpl-2026-27-5-rule-changes-new-features-announced), [Fix](https://www.fantasyfootballfix.com/blog-index/fpl-2026-27-new-rules/), [AllAboutFPL](https://allaboutfpl.com/2026/07/2026-27-fpl-season-new-rules-changes-whats-new-in-fpl/).

**All CONFIRMED unless noted:**

1. **BPS (Bonus Points System) tweaks** — designed to reduce overlap with defensive-contribution points and boost bonus prospects of goalkeepers, full-backs and attacking players. Exact deltas in §7.
2. **Live points/ranks:** projected bonus points added to player scores **after 20 minutes** of each fixture and updated live; overall rank, mini-league standings and H2H duels update live during matches.
3. **Later Gameweek "lockdown":** GW scores become final at **09:00 UK time on the day after the final match of the GW** (previously ~1 hour after the final whistle). Late Opta stat corrections (bonus/DefCon) now land more often.
4. **No AFCON free-transfer top-up in 2026-27** (AFCON is June/July 2027, out of season). In 2025-26 there was a GW16 top-up to 5 FTs — that does not recur.
5. **Rank-percentage history:** season history shown as percentile of all teams; career-average percentile comparisons.
6. **Price Change Predictor:** new official in-game tool showing every player's % progress toward a rise/fall (>100% = change expected; a separate "predicted progress" % arrives after a calibration period). **Price changes themselves now happen daily at 00:00 UK time** (officially stated — moved from the previous ~01:30 GMT/02:30 BST processing window); the underlying algorithm/thresholds remain proprietary — see §10 ([premierleague.com](https://www.premierleague.com/en/news/4680462/whats-new-in-202627-fantasy-price-change-predictor)).
7. **New squad-view info** (FDR, ownership, form, price-change likelihood per player) and Adobe Express GW recaps / AI team badges. Cosmetic — no optimizer impact.
8. **Position reclassifications: 11 players** (see §3.1).
9. **Chips: UNCHANGED from 2025-26** — two full sets of Wildcard/Free Hit/Bench Boost/Triple Captain, one set per half-season (8 chips total). First set **expires at the GW19 deadline: 13:30 GMT, Saturday 2 January 2027** ([premierleague.com](https://www.premierleague.com/en/news/4679873/all-you-need-to-know-about-changes-to-fpl-for-202627), [Fix](https://www.fantasyfootballfix.com/blog-index/fpl-2026-27-new-rules/)).
10. **Defensive contribution points RETAINED** for 2026-27, same structure as 2025-26 (no threshold changes announced; one low-quality aggregator claimed a "recalibration" — **not corroborated** by the official article, FFS, Fix or AllAboutFPL; treat thresholds as unchanged).
11. **Transfers: unchanged** — up to 5 FTs rollover confirmed again for 2026-27.

**No change was announced** to: core scoring values (goals/assists/CS/cards), squad rules, budget, £-hit cost, captaincy, auto-subs, sell-on fee. Treat the 2025-26 values (below, extracted from the live API) as the 2026-27 baseline, then re-verify from the 2026-27 `bootstrap-static` on launch.

## 3. Squad rules (CONFIRMED — API `game_settings` / `element_types`, unchanged for 2026-27)

Extracted from `bootstrap-static` (2025-26 values; no 2026-27 changes announced):

- **Squad size:** 15 (`squad_squadsize: 15`).
- **Budget:** £100.0m (`squad_total_spend: 1000`; all API prices are in **£0.1m units**, `ui_currency_multiplier: 10` — e.g. `now_cost: 62` = £6.2m).
- **Position quotas (exact, not min/max):** 2 GKP, 5 DEF, 5 MID, 3 FWD (`element_types[].squad_select` = 2/5/5/3; `squad_min_select`/`squad_max_select` are null).
- **Club limit:** max **3 players per Premier League club** (`squad_team_limit: 3`).
- **Starting XI:** 11 of the 15 start each GW (`squad_squadplay: 11`); 4 on the bench in priority order (bench slot 1 is always the reserve GK).
- **Formation constraints** (`squad_min_play` / `squad_max_play` per position):
  - GKP: exactly 1 (min 1, max 1)
  - DEF: min 3, max 5
  - MID: min 2, max 5
  - FWD: min 1, max 3
  - Valid formations: 3-4-3, 3-5-2, 4-3-3, 4-4-2, 4-5-1, 5-2-3, 5-3-2, 5-4-1 (any combo satisfying the mins with 10 outfielders).

## 4. Captain, vice-captain, automatic substitutions (CONFIRMED — long-standing rules, API `sys_vice_captain_enabled: true`)

- **Captain scores double** (×2). If the captain plays 0 minutes in the GW, the **vice-captain** is captained instead (×2). If neither plays, no multiplier is applied to anyone.
- **Triple Captain chip** makes the multiplier ×3 for that GW (applies to the vice if the captain doesn't play).
- **Automatic substitutions** (processed at the end of the GW, i.e. at lockdown):
  - A starter who plays **0 minutes** in the GW is replaced by the highest-priority bench player whose introduction keeps the formation legal (≥1 GKP exactly, ≥3 DEF, ≥2 MID, ≥1 FWD).
  - The starting GK is only ever replaced by the bench GK.
  - Players who played but got 0 or negative points are **not** substituted — only non-appearance triggers a sub.
  - If a fixture is postponed, players in it count as non-appearing for auto-sub purposes once the GW completes.
- Reference: official rules page `https://fantasy.premierleague.com/help/rules` (SPA — not fetchable statically; verify in-app after launch), and [premierleague.com FPL basics](https://www.premierleague.com/en/news/2174909).

## 5. Scoring system for 2026-27 (baseline CONFIRMED from live API `game_config.scoring` for 2025-26; no changes announced for 2026-27)

The 2025-26 API exposes the full scoring table in `game_config.scoring`. The official 2026-27 announcement changed **no outfield scoring values** — only BPS internals (§7). Values below are the ones to encode:

| Action | GKP | DEF | MID | FWD |
|---|---|---|---|---|
| Playing 1–59 min (`short_play`) | 1 | 1 | 1 | 1 |
| Playing ≥60 min (`long_play`) | 2 | 2 | 2 | 2 |
| **Goal scored** (`goals_scored`) | **10** | **6** | **5** | **4** |
| Assist (`assists`) | 3 | 3 | 3 | 3 |
| Clean sheet (`clean_sheets`; requires ≥60 min played) | 4 | 4 | 1 | 0 |
| Every 2 goals conceded while on pitch (`goals_conceded`) | −1 | −1 | 0 | 0 |
| Every 3 shot saves (`saves`) | 1 | — | — | — |
| Penalty save (`penalties_saved`) | 5 | — | — | — |
| Penalty miss (`penalties_missed`) | −2 | −2 | −2 | −2 |
| **Defensive contribution** (`defensive_contribution`, capped once per match) | 0 | **+2 at 10+ CBIT** | **+2 at 12+ CBIRT** | **+2 at 12+ CBIRT** |
| Yellow card (`yellow_cards`) | −1 | −1 | −1 | −1 |
| Red card (`red_cards`) | −3 | −3 | −3 | −3 |
| Own goal (`own_goals`) | −2 | −2 | −2 | −2 |
| Bonus (top-3 BPS in match) | 1–3 | 1–3 | 1–3 | 1–3 |

Notes (CONFIRMED):

- **Goalkeeper goals are worth 10 points** — raised from 6 in **2024-25** ("The points for each goal scored by a goalkeeper is being increased this season from six to 10" — [premierleague.com 2024-25 changes](https://www.premierleague.com/en/news/4058895)); confirmed in the live 2025-26 API (`goals_scored.GKP: 10`) and in the archived 2024-25 API (Wayback, Mar 2025: `goals_scored.GKP: 10`); no reversal announced for 2026-27.
- **Defensive contribution (introduced 2025-26, retained 2026-27):** DEF earn 2 pts for **10+ combined clearances, blocks, interceptions and tackles (CBIT)** in one match; MID/FWD earn 2 pts for **12+** of CBIT **plus ball recoveries** (CBIRT). GKs are ineligible (`GKP: 0`). Max 2 pts per player per match ([premierleague.com 2025-26 changes](https://www.premierleague.com/en/news/4362211/all-you-need-to-know-about-changes-to-fantasy-for-202526); API).
- **Red card** deduction includes the yellow-card deduction (a second-yellow red is −3 total, not −4); players sent off keep being penalized for goals their team concedes until full time (official rules page).
- **Clean sheet** requires being on the pitch for 60+ minutes (excl. stoppage time) and no goal conceded while on the pitch.
- **Assists (3 pts):** the "Fantasy assist" definition was **simplified for 2025-26** (fewer subjective exclusions; would have produced 41 extra assists in 2024-25) and carries into 2026-27 unchanged ([premierleague.com](https://www.premierleague.com/en/news/4373187/whats-new-for-202526-changes-in-fantasy-premier-league)).
- Dead fields in the API (`starts`, ICT components, `expected_*`, all `mng_*` manager fields) score **0** — the Assistant Manager chip's scoring hooks exist in the schema but are zeroed (see §8).
- The API scoring dict stores per-unit values (`saves: 1`, `goals_conceded: -1`); the divisors (per **3** saves, per **2** goals conceded) come from the official rules text, not the JSON.

## 6. Bonus points allocation (CONFIRMED)

- The three highest-BPS players in each **match** get 3, 2, 1 bonus points.
- Ties: tie for 1st → both get 3, third-best gets 1; tie for 2nd → 3/2/2; tie for 3rd → 3/2/1/1 ([FFS](https://www.fantasyfootballscout.co.uk/2025/07/21/what-are-fpl-bonus-points)).
- From 2026-27, **projected** bonus appears live after 20'; final bonus is settled at lockdown (09:00 next day).

## 8. Chips for 2026-27 (CONFIRMED: identical structure to 2025-26)

**Eight chips: two of each of Wildcard, Free Hit, Bench Boost, Triple Captain — one set per half-season.** No new chips; **the Assistant Manager chip (2024-25 one-off) does not exist** in 2025-26 or 2026-27 ([premierleague.com 25-26](https://www.premierleague.com/en/news/4362211/all-you-need-to-know-about-changes-to-fantasy-for-202526), [premierleague.com 26-27](https://www.premierleague.com/en/news/4679873/all-you-need-to-know-about-changes-to-fpl-for-202627); API `mng_*` scoring all zeros).

2025-26 API `chips[]` windows (expect identical shape for 2026-27; re-verify on launch):

| Chip (API name) | Set 1 window | Set 2 window | Type |
|---|---|---|---|
| Wildcard (`wildcard`) | GW2–GW19 | GW20–GW38 | transfer |
| Free Hit (`freehit`) | GW2–GW19 | GW20–GW38 | transfer |
| Bench Boost (`bboost`) | GW1–GW19 | GW20–GW38 | team |
| Triple Captain (`3xc`) | GW1–GW19 | GW20–GW38 | team |

- WC/FH start at GW2 because transfers are unlimited before GW1.
- **First-set expiry for 2026-27: the GW19 deadline, 13:30 GMT on Saturday 2 January 2027** (CONFIRMED, official article). Unused first-half chips are lost; they do **not** carry over.
- Second set available GW20 through GW38.
- **Only one chip may be active in any single gameweek** ("Only one chip can be played in a single Gameweek" — [premierleague.com chips article](https://www.premierleague.com/en/news/4679879/whats-happening-with-fpl-chips-in-202627), which also confirms Free Hit is "unavailable in Gameweek 1", corroborating the GW2 window start).
- Effects: **Wildcard** = unlimited free transfers that GW, changes permanent; **Free Hit** = unlimited transfers for one GW, squad reverts afterwards; **Bench Boost** = all 15 players' points count; **Triple Captain** = captain ×3. WC/FH cannot be cancelled once confirmed; playing WC/FH does **not** consume or reset banked FTs (they carry through and keep accruing).

## 9. Transfers (CONFIRMED from API + official; unchanged for 2026-27)

- **Unlimited free transfers before the GW1 deadline** (squad can be rebuilt freely pre-season).
- **1 free transfer added per gameweek** (credited at each deadline).
- **Banking: up to 5 free transfers** total (`max_extra_free_transfers: 4` = 1 base + 4 extra; official articles repeatedly say "roll over up to five" — [premierleague.com](https://www.premierleague.com/en/news/4679873/all-you-need-to-know-about-changes-to-fpl-for-202627)). Rule in place since 2024-25.
- **Extra (non-free) transfers cost −4 points each**, deducted from that GW's score.
- **Hard cap: 20 transfers in a single gameweek** (`transfers_cap: 20`); does not apply in a Wildcard/Free Hit GW (transfers are unlimited then). Publicized as a rule for 2024-25 (the API field `transfers_cap: 20` already existed in the 2023-24 API per Wayback snapshots); still 20 in the 2025-26 API; **PRESUMED retained** for 2026-27 (no change announced). *(Note: the [24-25 changes article](https://www.premierleague.com/en/news/4058895) covers the 5-FT rollover but does not itself mention the 20-cap; the API field is the primary evidence.)*
- Free transfers are **not** lost when playing WC/FH (you re-emerge with the same bank, which continues accruing).
- **No AFCON top-up in 2026-27** (the 2025-26 GW16 top-up to 5 FTs was a one-off — [FFS](https://www.fantasyfootballscout.co.uk/2025/12/08/fpl-gameweek-16-free-transfer-top-up-all-you-need-to-know)).

## 10. Player pricing (mechanics CONFIRMED at rule level; algorithm unofficial)

- Starting prices for 2026-27: **not yet released** (due in launch week — [Fix](https://www.fantasyfootballfix.com/blog-index/fpl-2026-27-new-rules/)). API prices are in £0.1m units.
- **In-season price changes** are driven by net transfer-market activity; at most one change (±£0.1m) per player per day (community knowledge — no official per-day maximum stated). **Official (new for 2026-27): prices are locked until the GW1 deadline (18:30 BST, Fri 21 Aug 2026), then change daily at 00:00 UK time** (previously processed ~01:30 GMT/02:30 BST). The algorithm/thresholds remain proprietary (**UNCERTAIN** internals). The official **Price Change Predictor** shows each player's % progress toward a rise/fall (>100% = change expected), on a dedicated sortable page, player profiles and transfer screens ([premierleague.com](https://www.premierleague.com/en/news/4680462/whats-new-in-202627-fantasy-price-change-predictor)).
- **Selling price / sell-on fee (CONFIRMED, API):** `transfers_sell_on_fee: 0.5`, `element_sell_at_purchase_price: false` — you bank **50% of any profit, rounded down to the nearest £0.1m** (e.g. bought 8.0, now 8.3 → sell at 8.1). Price falls are borne in full.
- Budget/prices interact only through purchase/sale; team value itself isn't scored.

## 11. Deadlines, lockdown, leagues (CONFIRMED)

- **Deadlines: 90 minutes before the first kickoff of each gameweek** (standard since 2019-20; e.g. 2025-26 GW1 kicked off 19:00 UTC with a 17:30 UTC deadline — visible in the API events/fixtures data).
- **NEW 2026-27 lockdown:** scores final at **09:00 UK the morning after the GW's last match** — the scoring engine should treat GW points as provisional until then (late Opta corrections to bonus/DefCon are now expected rather than rare).
- H2H league scoring (API): win 3 / draw 1 / loss 0; tiebreak `+goals_scored, -goals_conceded` (`league_h2h_tiebreak_stats`). Classic-league tie-break rules are not exposed in the API (verify at launch). Private classic leagues up to 30 joined (`league_join_private_max: 30`); new Elite (top-1%, top-10%) invitational leagues continue from 2025-26.
- FPL Cup settings were null in the 2025-26 end-of-season API (`cup_start_event_id: null` etc.); cup format for 2026-27 TBD at launch.

## 12. Encoding checklist for the optimizer / scoring engine

1. **Squad MILP constraints:** 15 players; exactly 2/5/5/3 GKP/DEF/MID/FWD; ≤3 per club; Σ price ≤ £100.0m (1000 units); XI of 11 with GK=1, DEF≥3, MID≥2, FWD≥1.
2. **Transfer dynamics:** FT_{t+1} = min(FT_t − used + 1, 5), FT ≥ 0 hits at −4 each, ≤20 transfers/GW, WC/FH gameweeks: unlimited, FT bank passes through unchanged (+1 accrual still applies).
3. **Chip planner:** 8 chips, ≤1 per GW; set-1 {WC1,FH1 ∈ GW2–19; BB1,TC1 ∈ GW1–19} all expire at GW19 deadline (2027-01-02 13:30 GMT); set-2 ∈ GW20–38. No Assistant Manager.
4. **Scoring:** table in §5 (note GK goal = 10, DefCon +2 with 10/12 thresholds, saves ⌊S/3⌋, conceded −⌊C/2⌋ for GK/DEF).
5. **Bonus model:** retrain/adjust BPS→bonus projection for 2026-27 deltas (tackled removed, CBI 1/3, GK save restructure) — expect fewer CB bonuses, more GK/attacker bonuses.
6. **Prices:** 0.1m units; sell price = purchase + ⌊(now−purchase)/2⌋ (floored to 0.1m) when in profit, else now_cost.
7. **Data plumbing:** poll `bootstrap-static` for the `2026_27` flip; then re-extract `game_settings`, `game_config.rules`, `game_config.scoring`, `chips[]`, `element_types[]`, `events[]` (GW1 deadline), `elements[]` (launch prices) and diff against this document.
