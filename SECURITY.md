# Security Policy

PITCHSIDE is a static site plus a batch pipeline with a single optional secret
(an odds-API key), but if you believe you have found a security issue — leaked
credentials, a way to poison the published data bundle, a vulnerability in the
Actions workflows, or anything in the local FastAPI server — please report it
privately via **GitHub Security Advisories** on this repository
(*Security → Report a vulnerability*) rather than a public issue; for
non-sensitive hardening suggestions a regular GitHub issue is fine. Reports are
read by the maintainer and you can expect an acknowledgment within a week.
Please do not test against the live GitHub Pages deployment beyond what a
normal page load does.
